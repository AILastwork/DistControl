# DistControl Server

Сервер устанавливается на один постоянно включённый компьютер Windows.

1. Запустите `DistControl-Server-Setup.exe` двойным щелчком.
2. Подтвердите запрос прав администратора.
3. Запустите `DistControl.CentralAdmin.exe` от учётной записи, входящей в доменную группу `Domain Admins`.
4. Укажите адрес сервера. Отдельный ключ администратора не требуется.
5. После установки нового клиента разрешите его заявку на вкладке «Заявки».

Для других администраторов раздавайте `DistControl-AdminConsole-0.8.19.zip`.
В нём рядом лежат `DistControl.CentralAdmin.exe` и `DistControl.Admin.exe`;
ZIP нужно распаковать целиком. Он собирается через `build-admin-console.cmd`
или автоматически вместе с серверным и клиентским установщиками.
Если редактор не найден рядом, консоль проверяет `%ProgramFiles%\DistControl Server`,
путь клиента из реестра и стандартные папки его установки. Ошибка перечисляет
все проверенные полные пути. Версия приложений показана справа внизу их окон.

Ручной сценарий `Install-DistControlServer.ps1` оставлен в ZIP как резервный
вариант. Для обычной установки PowerShell не требуется.

По умолчанию сервер слушает TCP-порт `8765`. Для первого варианта используется
HTTP внутри доверенной локальной сети. Не публикуйте этот порт напрямую в интернет.

Сервер хранит политики, журналы, историю изменений и пакеты обновлений в
`%ProgramData%\DistControlServer`. Клиенты продолжают работать по последней
применённой политике, если сервер временно недоступен.
