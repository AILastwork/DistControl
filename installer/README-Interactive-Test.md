# DistControl Interactive Test

Экспериментальный локальный клиент проверяет запуск `dkcl64.exe` от имени
пользователя активного сеанса Windows без ввода и хранения его пароля.

- Центральный сервер не настраивается.
- Служба автоматического обновления не устанавливается.
- Обычная служба `dkclient` удаляется.
- Вместо неё создаётся защищённая задача Windows `DistControl Interactive dkclient`.
- Задача запускается только при интерактивном входе выбранного пользователя.

Перед установкой закройте DistControl. После установки откройте DistControl,
подключите тестовый токен и проверьте с другого компьютера, что владельцем
показывается фактическая учётная запись пользователя.

Это проверочный вариант. Для возврата к обычной службе повторно запустите
стандартный установщик DistControl и укажите учётные данные службы.
