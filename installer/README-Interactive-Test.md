# DistControl System Service Test

Экспериментальный локальный клиент проверяет запуск `dkcl64.exe` именно как
службы Windows `dkclient` под `LocalSystem`, без ввода и хранения пароля
пользователя.

- Центральный сервер не настраивается.
- Служба автоматического обновления не устанавливается.
- Создаётся обычная автоматически запускаемая служба Windows `dkclient`.
- Служба работает под `LocalSystem`, поэтому пароль сотрудника не нужен.
- Фактическое имя сотрудника DistControl записывает в общий `usage.json` при
  успешном подключении токена и использует эту запись вместо владельца `SYSTEM`.

Перед установкой закройте DistControl. После установки откройте DistControl,
подключите тестовый токен и проверьте с другого компьютера, что владельцем
показывается фактическая учётная запись пользователя.

Это проверочный вариант. Для возврата к запуску службы под доменной учётной
записью повторно запустите стандартный установщик DistControl.
