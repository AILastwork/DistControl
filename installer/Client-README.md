# Установка клиента DistControl

## Что устанавливается

- `DistControl.exe` — клиент для подключения разрешённых USB-токенов;
- `DistControl.Agent.exe` — фоновая служба `DistControlAgent` для связи с центральным сервером;
- `DistControl.Updater.exe` — автоматическое обновление клиента;
- компоненты DistKontrolUSB (`dkclient`) и необходимые драйверы.

Агент устанавливается вместе с клиентом автоматически. Отдельно запускать его не нужно, пароль пользователя для его работы не требуется.

## Установка

1. Запустите `DistControl-Setup.exe` от имени администратора или установите MSI-пакет.
2. Проверьте автоматически выбранную текущую учётную запись Windows.
3. Проверьте адрес центрального сервера `http://10.14.32.179:8765`.
4. Проверьте общую папку таймеров `\\dfs\fs\IT\soft\DistKontrol\time`.
5. Завершите установку и дождитесь, пока администратор подтвердит компьютер на вкладке «Заявки».
6. Запустите DistControl из меню «Пуск».

## Где находятся файлы

- программа: `%LOCALAPPDATA%\Programs\DistControl`;
- настройки, политика и журналы: `%LOCALAPPDATA%\DistControl`.

Агент получает настройки и обновления с сервера, отправляет журнал работы токенов и выполняет подтверждённые команды администратора. Обновление клиента через сервер выполняется в фоне и не требует ввода пароля на рабочем компьютере.
