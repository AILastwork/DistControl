# DistControl 0.6.2

В админке VPN назначается прямо напротив каждого токена в таблице «Токены → VPN».

- Выбор «Не назначен», «БЕЗ VPN» или установленного профиля Windows VPN.
- Поиск токенов, ввод названия VPN и автосопоставление неназначенных строк.
- Сохранение всех назначений одной операцией с предупреждением о несохранённых изменениях.
- Недоступные VPN-профили сохраняют прежнее назначение до ручной замены.
- Перестановка и сохранение ширины столбцов админки.
- Политика выбранного пользователя открывается из его реального каталога AppData.
- Токены, подключённые текущим пользователем, отмечены фиолетовым.
- Исправлено применение выбора VPN в выпадающем списке.

Программа устанавливается для выбранного пользователя. В этой версии общий таймер
сохраняется синхронно; это точка возврата перед переходом на локальное сохранение
с фоновой синхронизацией.

Проверка: Debug/Release-сборка и автоматические C++ тесты.

Файлы: DistControl-Setup.exe, DistControl-0.6.2-win64.zip и SHA256 архива.
