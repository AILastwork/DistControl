# DistControl 0.6.3

Таймер, обновление статусов и работа с VPN.

- Таймер сначала сохраняется на компьютере, общая папка обновляется скрытым
  процессом: свои изменения отправляются сразу, чужие таймеры — раз в 30 секунд.
- Отсчёт 20 минут ведётся по UTC; повреждённый локальный файл таймеров
  откладывается как `*.corrupt-<время>`, а работа продолжается.
- При выходе из Windows и выключении компьютера подключённые токены отключаются.
- Статусы токенов обновляются автоматически каждые `refreshSeconds` (по умолчанию
  5 секунд) с сохранением выделения и прокрутки.
- VPN, общий для нескольких токенов, не отключается, пока им пользуется хотя бы
  один из них; подключение ещё одного токена не переподключает работающий VPN.
- Ответ службы «FAILED» или отсутствие ответа на `USE` перепроверяется несколько
  секунд: если токен подключился, показывается успех.
- Интерфейс: подключённые токены — синий фон и белый жирный текст, выбранный —
  рамка; приписка «[Сеть: …]» у всех токенов; кнопка «Подключить/Отключить»;
  цветная строка состояния.
- Админка: кнопки «← Добавить выбранные (N)» и «Убрать выбранные (N) →» над
  списками; в «Токены → VPN» можно вставить скопированное название VPN.
- Диалог ввода логина и пароля VPN удалён: используются данные Windows.

Проверка: Debug/Release-сборка без предупреждений, автоматические C++ тесты и
проверка помощника синхронизации. Окна и работа с реальной службой и VPN
проверяются на рабочем месте.

Файлы: DistControl-Setup.exe, DistControl-0.6.3-win64.zip и SHA256 архива.
