# DistControl 0.6.4

Установка без лишних шагов, «Без VPN» по умолчанию и отчёт по использованию.

- Установщик сам ставит драйвер VirtualHere USB 3 (`vhusb3hc`, подписан
  Microsoft), если его нет: `dkcl64.exe` больше не нужно запускать вручную и
  отдельно вводить пароль администратора. Уже установленный драйвер не трогается.
- Пароль учётной записи службы проверяется сразу после ввода: не больше трёх
  неверных попыток, понятные сообщения о блокировке, отключении и истёкшем
  пароле; при недоступном домене можно продолжить без проверки.
- Если служба `dkclient` не ответила сразу после установки, установка
  завершается предупреждением, а не ошибкой.
- Новые токены, добавленные пользователю в админке, сразу получают «Без VPN»;
  кнопка «Без VPN для всех ненастроенных» в окне «Токены → VPN». Токен с «сеть не
  настроена» по-прежнему нельзя подключить.
- В папке установки `installer` остаются только скрытые скрипты удаления.
- События подключения, отключения, продления и причина автоотключения
  записываются в общую папку рядом с таймерами (`usage-log`).
- Кнопка «Отчёт по использованию…» в админке: HTML-отчёт за выбранный период по
  всем компьютерам с фильтрами по компьютеру и пользователю.

Проверка: Debug/Release-сборка без предупреждений, автоматические C++ тесты,
проверки установщика и помощника синхронизации, пробный прогон установщика.
Не проверены на рабочем месте: установка драйвера на чистый компьютер, окно
ввода пароля, кнопка отчёта в админке и запись в общую папку `usage-log`.

Файлы: DistControl-Setup.exe, DistControl-0.6.4-win64.zip и SHA256 архива.
